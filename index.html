1. Problem Statement

Colleges collect attendance, assignment and academic performance data. However, these data points are often viewed separately.

This project explores whether academic data can help identify students who may need support before examinations.

2. Analytical Question

Can attendance, study hours, assignment completion and previous marks help identify students at risk of low final performance?

3. Dataset

A synthetic dataset of 300 students is used because real student records are private.

Variable Description
Student ID Unique student identifier
Attendance Attendance percentage
Study Hours Study hours per day
Assignments Completed assignments
Previous Marks Previous academic marks
Final Marks Final academic marks

4. Data Preparation

  • Missing values were checked.
  • Missing study hours were replaced using the median.
  • Missing assignment values were replaced.
  • Duplicate records were removed.
  • An early-warning risk score was calculated.

5. Analysis Methods

  • Average calculation

  • Performance comparison
  • Early-warning risk analysis

10. C Programming Code

This C program uses the same risk conditions as the interactive calculator. Save this code separately as student_performance_risk.c to compile and run it. 

#include <stdio.h>

int main()
{
    int n, i, assignments, risk;
    float attendance, studyHours, previousMarks, finalMarks;
    float totalMarks = 0, averageMarks;

    printf("STUDENT PERFORMANCE ANALYTICS\n");
    printf("Enter number of students: ");
    scanf("%d", &n);

    if (n <= 0)
    {
        printf("Invalid number of students!\n");
        return 0;
    }

    for (i = 1; i <= n; i++)
    {
        risk = 0;

        printf("\n--- Student %d ---\n", i);

        printf("Enter attendance percentage: ");
        scanf("%f", &attendance);

        printf("Enter study hours per day: ");
        scanf("%f", &studyHours);

        printf("Enter completed assignments: ");
        scanf("%d", &assignments);

        printf("Enter previous marks: ");
        scanf("%f", &previousMarks);

        printf("Enter final marks: ");
        scanf("%f", &finalMarks);

        totalMarks = totalMarks + finalMarks;

        if (attendance < 65)
            risk++;

        if (studyHours < 2)
            risk++;

        if (assignments < 6)
            risk++;

        if (previousMarks < 50)
            risk++;

        printf("Risk Score: %d out of 4\n", risk);

        if (risk == 0)
            printf("Risk Level: Low Risk\n");
        else if (risk == 1)
            printf("Risk Level: Watch\n");
        else if (risk == 2)
            printf("Risk Level: Medium Risk\n");
        else
            printf("Risk Level: High Risk\n");

        if (finalMarks < 40)
            printf("Suggestion: Provide extra academic support.\n");
        else
            printf("Suggestion: Continue regular study habits.\n");
    }

    averageMarks = totalMarks / n;

    printf("\nTotal Students: %d\n", n);
    printf("Average Final Marks: %.2f\n", averageMarks);
    printf("Analysis completed successfully!\n");

    return 0;
}

11. Insights

  • Low attendance can be an early warning sign.
  • Study time and assignment completion can also matter.
  • Students with multiple warning signs may benefit from support.
  • A risk score does not guarantee a student's final result.

12. Recommendations

  • Provide mentoring to students with multiple warning signs.
  • Arrange revision classes and assignment support.
  • Monitor attendance and academic progress regularly.
  • Protect student information and use data responsibly.

13. Limitations

  • The sample dataset is synthetic.
  • The risk model uses simple rules.
  • Many other factors can affect academic performance.
  • The calculator analyses one student at a time.
